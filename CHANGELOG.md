# Changelog

## 1.1.0 — 2026-11-16

- Brighter 8-color palette and 22 redesigned, softer symbols.
- Original layered folder shape with a visible dark rear tab and subtle depth.
- Consistent artwork in Project folders and customization previews.
- Old preset colors upgrade automatically; custom colors and folder assignments remain intact.
- Updated cover and artwork previews, with editable SVG sources.


## 1.0.0 — 2026-11-16

- Automatic folder styling with 19 editable name rules.
- GUID-based per-folder overrides and multi-folder editing.
- Independent color and symbol selection, 8 presets and 22 original symbols.
- Transparent custom PNG support without changing texture import settings.
- Undo/Redo, reset to automatic, and native-folder overrides.
- Shared settings outside the package directory.
- Editor-only assembly and cached Project-window rendering.
- Unity 2022.3 and Unity 6 validation.
